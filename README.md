# 🔐 Local Network Security Scanner

A beginner-friendly defensive security project built with **Python, Nmap and Kali Linux**.

The project aims to make basic network reconnaissance and security assessment easier to understand by analyzing hosts, open ports and running services.

## 🎯 Project Goal

The main goal of this project is to apply the networking and Nmap concepts learned during my cybersecurity studies in a practical project.

The project focuses on:

* Host discovery
* Port scanning
* Service detection
* Basic reconnaissance
* Security observations
* Simple security reporting

## 🛠️ Technologies

* Python
* Nmap
* Kali Linux
* Linux

This project is being developed to reinforce the following cybersecurity concepts:

**Linux → Networking → IP → Ports → Services → Nmap → Reconnaissance → Security Assessment**
